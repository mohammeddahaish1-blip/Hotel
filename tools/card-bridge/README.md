# جسر قارئ البطاقات (Card bridge)

برنامج صغير يعمل على جهاز الاستقبال ويوصل **قارئ البطاقات الذكية** (الشريحة) بنظام نُزُل.
المتصفح لا يستطيع التحدث مع قارئ الشرائح مباشرة، فهذا البرنامج يقرأ البطاقة ويعطي البيانات للنظام عبر `127.0.0.1` فقط (لا شيء يخرج من الجهاز إلا إلى صفحة نُزُل نفسها).

> أجهزة **قراءة MRZ** (التي تعمل مثل لوحة المفاتيح: تمرّر البطاقة أو الجواز فتُكتب الأسطر) **لا تحتاج هذا البرنامج**. توصلها بـ USB وتضغط «قراءة البطاقة من الجهاز» في النظام مباشرة.

## التشغيل

يحتاج Node.js 18 أو أحدث على جهاز الاستقبال.

```bash
# للتجربة الآن بدون جهاز: يرجع بطاقة تجريبية باسم TEST CARD
node server.mjs --mock

# مع قارئ حقيقي: أمر أداة الشركة المصنّعة التي تطبع بيانات البطاقة
node server.mjs --cmd "C:\Vendor\ReadCard.exe --json"
```

ثم في نُزُل: الحجوزات > حجز جديد > «تسجيل نزيل بالبطاقة». أول مرة قد يطلب المتصفح إذن «الوصول للشبكة المحلية»؛ وافق عليه.

## ما يجب أن تطبعه أداة القارئ (`--cmd`)

واحد من الشكلين:

1. أسطر MRZ (سطر في كل سطر)، أو
2. JSON:
```json
{
  "fields": {
    "full_name": "AHMED SAID AL BALUSHI",
    "full_name_ar": "أحمد سعيد البلوشي",
    "nationality": "OMN",
    "doc_type": "oman_id",
    "doc_number": "12345678",
    "doc_expiry": "2030-04-15",
    "date_of_birth": "1990-01-01",
    "gender": "M"
  },
  "image": "data:image/jpeg;base64,..."
}
```
`doc_type` واحد من: `oman_id`, `gcc_id`, `passport`, `resident_card`, `other`. الصورة اختيارية وتُحفظ في ملف النزيل (محمية ومسجّل من يفتحها).

## الأمان

- يستمع على `127.0.0.1` فقط، ويقبل الطلبات من مواقع نُزُل فقط (`ALLOWED_ORIGINS`، الافتراضي: الموقع الرسمي و`localhost:3000`).
- لا يحفظ ولا يطبع بيانات البطاقات في السجل.
- البطاقة الوطنية العُمانية الذكية تحتاج أداة القراءة الرسمية المعتمدة؛ عند اختيار الجهاز نكتب لها أمر `--cmd` المناسب.
